## Project Overview

his repository contains the practical implementation, configuration, documentation, and learning materials for Oracle Fusion Financials – Accounts Receivable (AR).

The project focuses on understanding and implementing the main Accounts Receivable processes in Oracle Fusion Cloud Financials, from customer setup and invoice creation to receipt processing, reconciliation, and financial reporting.

## Project Objectives

* Understand the Oracle Fusion Accounts Receivable process.
* Create and manage customer accounts and customer sites.
* Configure Customer Profile Classes.
* Configure Transaction Types and Transaction Sources.
* Configure AutoAccounting.
* Create and manage customer invoices.
* Process Credit Memos and Debit Memos.
* Configure Receipt Classes and Receipt Methods.
* Create and apply customer receipts.
* Perform customer account reconciliation.
* Manage adjustments and receipt applications.
* Understand and use AutoInvoice.
* Review customer balances and aging reports.
* Transfer Receivables accounting entries to General Ledger.
